# java-android-xhealth-records

> 医疗健康记录类 Android 客户端（历史项目学习存档）。

## 项目简介

一个面向医疗健康场景的 Android 应用客户端，围绕「个人健康档案」提供就诊记录、临床门诊、医院信息浏览与即时消息等功能模块。项目源自企业内部工程（含 `.svn` 版本管理历史），归档于此仅供学习参考。

## 功能模块

- **医疗记录**：健康档案与就诊记录列表展示、分组展开（ExpandableList）
- **临床信息**：临床门诊、医院信息浏览与检索
- **会话消息**：即时通讯会话列表与侧滑操作
- **基础框架**：全局 Crash 捕获（CrashHandler）、推送接收（CustomReceiver）

## 技术栈

- 语言：Java
- 架构：Adapter 体系 + Activity/Fragment 分层
- 其他：SVN 原始工程直接迁移（仓库中保留 `.svn` 目录）
